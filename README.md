# Simple Port Scanner

A beginner Python tool to scan a range of TCP ports on a target IP or domain.

## Usage

Run `python port_scanner.py` and follow prompts.

## Example

python port_scanner.py
Target IP/domain: scanme.nmap.org
Start port: 20
End port: 25

text

## Requirements

- Python 3.x

## Disclaimer

Use only on hosts you own or have permission for!
